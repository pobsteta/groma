# groma (paquet Python)

Fonctions pures de l'inventaire vidéo : numérotation, azimuts, ajustement
de cercles, détection des troncs dans une tranche, géoréférencement,
hauteurs par houppiers, contrôles LiDAR, rapprochement provisoire →
définitif, schéma et écriture du GeoPackage `inventaire_video.gpkg`.

```bash
cd core
pip install -e ".[dev]"
pytest
```
